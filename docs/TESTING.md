# Testing

There are three layers of tests. The first two run in CI on every pull request.

## 1. Unit tests (`npm run test:unit`)

Mocha tests in `test/unit/` cover the PNG module in `src/png/`, which is the
code that rewrites files and so can do real damage:

- Every fixture round-trips byte for byte (parse, then encode).
- Editing, adding, removing and retyping text fields changes only those fields;
  image data and chunk order are untouched.
- Broken files (wrong signature, truncated, bad checksum, no IEND) are rejected.
- Keyword and Latin-1 validation.

The tests save the files they produce to `test/output/`, and
`scripts/validate-output.py` then opens each one with Pillow, an independent
PNG decoder, and checks the image decodes and the text fields match. This
needs Python 3 with Pillow (`pip install pillow`).

Fixtures in `test/fixtures/` are generated by `scripts/make-fixtures.py`
(also with Pillow, so they were not written by our own encoder). They include
a made-up SillyTavern card with `chara` (V2) and `ccv3` (V3) chunks. Re-run
the script after changing it; it also copies the fixtures into the test vault.

## 2. UI tests (`npm run test:e2e`)

WebdriverIO specs in `test/specs/` drive a real copy of Obsidian through
[wdio-obsidian-service](https://github.com/jesse-r-s-hines/wdio-obsidian-service).
It downloads Obsidian into `.obsidian-cache/`, opens a fresh copy of
`test/vaults/simple` with this plugin installed, and runs each test.

By default the tests run on two versions: the manifest's `minAppVersion` and
the latest release. Set `OBSIDIAN_VERSIONS`, e.g. `OBSIDIAN_VERSIONS=latest/latest`,
to choose others.

On Linux without a desktop, run them under a virtual display:

```bash
xvfb-run -a npm run test:e2e
```

## 3. Manual checks

Before a release, try the plugin in a real vault (a copy, not your main one):

- [ ] Click a PNG in the file explorer: it opens in the metadata view with a preview.
- [ ] Edit a field and save: the change survives closing and reopening the file.
- [ ] A `.png.bak` copy of the original appears next to the file after the first save.
- [ ] The saved image still opens correctly in another app (browser, image viewer).
- [ ] Turn off "Open PNG files in metadata view": PNGs open in Obsidian's viewer again.
      Right-click → "Open in metadata view" still works.
- [ ] Mobile: the view opens and saves on iOS or Android.
- [ ] SillyTavern card: after editing a card's fields here, SillyTavern still imports it.
